# Visualizer direction

Start fresh with MilkDrop3 as the main reference. Build an independent engine with its own preview and a small adapter into Musimo.

Each song should create its own evolving visual journey. Support organic transformations, contrast, anticipation where whole-song analysis permits it, and visual memory when musical ideas return. Shapes and visual language can change. Avoid fixed genre templates and unrelated preset switching.

First milestone: one song with a compelling continuous visual journey. Discover the engine and visual approach using actual running examples before implementation.

See the [discovery handoff](visualizer-handoff.md) for the full brief and reset state.
