# Code of conduct

Treat people respectfully in issues, pull requests, reviews and other project spaces. Discuss the code and its consequences. Disagreement is welcome; insults, threats, harassment, discriminatory behavior and publishing private information are not.

Do not post credentials, unauthorized recordings or requests to help commit infringement. Keep reports reproducible and relevant. Respect a maintainer's decision to close or defer a request.

Maintainers may edit or remove content, close discussions, warn participants, or restrict participation according to the behavior and its impact. A serious privacy or safety incident may require an immediate restriction. Decisions should be explained when doing so does not expose someone else's private information.

Report conduct concerns privately to **ccleahy2020@gmail.com**. Describe what happened, where, and any context needed to assess it. Reports will be handled as privately as practical, but absolute confidentiality cannot be promised. For a concern involving the maintainer, GitHub's platform reporting tools remain available.

This is a project participation policy. It does not alter the software licence or promise a particular response time.
