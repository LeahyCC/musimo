# Governance

Musimo is maintained by **Colin Leahy**, [LeahyCC on GitHub](https://github.com/LeahyCC). Project contact: **ccleahy2020@gmail.com**. Security reports use the process in [Security](SECURITY.md).

The maintainer decides scope, reviews contributions and publishes releases. Contributors retain copyright in their work and grant the rights described in [Contributing](CONTRIBUTING.md). A contribution does not automatically grant repository administration or release access.

Small fixes can be proposed directly. Significant changes should start with an issue explaining the user problem, complete flow, tradeoffs and maintenance cost. Decisions should be recorded in the issue, pull request or relevant design note. There is no fixed voting system or release schedule.

The current priorities are responsive search, reliable downloads, safe file handling, clear failure states and a usable self-hosted setup. Broad new integrations come after these basics work.

If maintenance arrangements change, update this file and repository ownership explicitly. Forks are allowed under the MIT licence; use distinct branding where necessary to avoid implying upstream endorsement.
